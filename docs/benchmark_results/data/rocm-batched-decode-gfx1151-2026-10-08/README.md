# Raw data for rocm-batched-decode-gfx1151-2026-10-08.md

One directory per guarded session (`s1/` to `s6/`, described in the page's Environment section), each holding the harness, probe, model-level and `mlxcel-bench-decode` outputs and the server logs; `guard_s*.log` are the matching `scripts/rocm_gpu_guard.sh` logs (sessions with a rejected attempt show it, and only the clean attempt's outputs are kept). Kernel traces are not committed (hundreds of MB); the `*/trace*/pbd_kernel_stats.csv` files are rocprofv3's per-kernel summaries of the model-level runs. `harness/` has the session scripts (`run_all.sh` and `run_matrix.sh` for `s1/`, `run_s2.sh` to `run_s6.sh` for the others) and the trace analysis (`step_split.py` for the model-level decode window, `analyze_trace.py` with `profile_driver.py` for the server windows). Local paths are replaced by `<meas>` (the measurement directory) and the repository root.
