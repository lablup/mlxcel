# Benchmark decision archive — v0.5.1

[Benchmark index](../README.md)

This groups records by the first stable release tag containing the report, verified from Git trees, not by filename dates. It is **not** a benchmark of that release binary. Each linked frozen record preserves the actual measured commits (including dirty/branch builds), hardware, model, flags, repetitions, dispersion, attribution and unmeasured cells. Later corrections present at the consolidation snapshot are included; decisions describe the experiment, not necessarily today's defaults. `unreleased` means no stable tag yet contains the report.

## History-boundary prompt-cache snapshot (issue #1143)

History-boundary snapshots were validated through cache/progress behavior on M1 Ultra, not absolute latency: machine load was about 22. TTFT, peak memory, concurrency pressure and the 31B rotating-cache checkpoint remained unmeasured. Preserve the mechanism result without converting saved prefill work into an unsupported time claim.

## Post-completion prompt-cache warm-up (issue #1144)

Background warmup extends history snapshots to cover the assistant reply, reducing the next turn's prefill work. M1 Ultra load prevented an honest TTFT/latency claim; the record measures saved tokens instead. The 31B checkpoint, idle power cost and wider concurrent behavior remained unmeasured.
