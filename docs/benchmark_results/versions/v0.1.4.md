# Benchmark decision archive — v0.1.4

[Benchmark index](../README.md)

This groups records by the first stable release tag containing the report, verified from Git trees, not by filename dates. It is **not** a benchmark of that release binary. Each linked frozen record preserves the actual measured commits (including dirty/branch builds), hardware, model, flags, repetitions, dispersion, attribution and unmeasured cells. Later corrections present at the consolidation snapshot are included; decisions describe the experiment, not necessarily today's defaults. `unreleased` means no stable tag yet contains the report.

## Gemma 4 MTP speculative decoding

Historical Gemma 4 MTP measurements showed hardware- and batching-dependent gains, including roughly 1.87x on Unified 12B and 1.2–1.4x on 31B on M5 Max. Hardware gate descriptions in this evolving report are historical, not the current support matrix; later M3 gate, exactness and batched records supersede them. Do not infer B>1 support from B=1 speedups.

[Full record and reproduction](https://github.com/lablup/mlxcel/blob/2dc8ed47b30dc204d892328098e8cc34ec02ddc1/docs/benchmark_results/gemma4-mtp-speculative-decoding.md).
