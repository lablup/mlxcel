# 기술 보고서: PR #2736 — 주요 모델 ROCm 측정 결과

**날짜**: 2026-10-30
**상태**: 완료
**위험 수준**: 낮음

## 요약

Radeon 8060S(gfx1151)에서 mlxcel 커밋 `63b1ad9d`로 측정한 4비트 체크포인트 15개의 텍스트 디코딩 원시 결과 45개를 저장합니다. 모델마다 3회 모두 성공했고 모든 회차가 GPU 경합 검사를 통과했습니다.

## 문제 정의

세션용 통합 CSV에는 저장소의 기존 원시 결과 형식에 없는 분류·회차 열이 추가돼 있었습니다. 중앙값만 저장하면 반복 실행별 시간 측정 근거를 잃게 됩니다.

## 변경 요약

공개 CSV는 모든 측정 필드를 보존하며 `decode_path`로 끝나는 기존 ROCm 20열 형식을 사용합니다. 헤더를 제외한 데이터 행 1–15, 16–30, 31–45가 각 회차입니다. 인접 JSON에 회차 경계, 순환 실행 순서, 체크포인트 리비전, 바이너리 해시와 가드 결과를 기록합니다.

입력 512토큰, 출력 128토큰, 워밍업 20토큰, greedy 디코딩, 배치 크기 1 조건입니다. VLM에도 텍스트만 입력했습니다. Qwen3.6 MoE는 원본의 8비트 라우터 예외를 유지하며 Gemma 3 인덱스는 웨이트 변경 없이 보정했습니다.

## 검증과 한계

원본 45개 행과의 정확한 일치, 헤더 호환성, 모델별 3회 실행, 토큰 수, 엔진 경로와 바이너리 해시 불변을 검증했습니다. 런타임 코드는 변경하지 않습니다. 결과는 해당 호스트·조건의 처리량이며 생성 품질, 이미지 처리 성능 또는 다른 런타임 대비 가속을 입증하지 않습니다. 원본 세션 로그는 로컬에 유지하고 경합 검사를 통과한 가드 로그의 해시를 출처 JSON에 기록합니다.
