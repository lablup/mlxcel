# 기술 보고서: PR #2279 — 유지보수되는 YAML 파서

**작성일**: 2026-10-12
**상태**: 검증 완료
**위험도**: 중간

## 요약

CLI와 surgery 설정 로더가 역직렬화 기능만 활성화한 serde-saphyr 1.3.0을 사용합니다. RUSTSEC-2024-0449로 CI를 차단했던 serde_yaml과 unsafe-libyaml 의존성 경로를 제거합니다.

## 문제 정의

두 설정 경로가 유지보수되지 않는 파서에 의존했습니다. 보안 권고를 무시하면 지원되지 않는 의존성이 실행 경로에 남습니다. 교체 과정에서 문서 순서에 따른 언어 우선순위, 스키마 검증, 작업별 숫자 오류를 보존해야 합니다.

## 기술적 선택과 그 이유

두 로더는 YAML 병합 키를 일반 키로 처리하며 YAML 1.2 불리언 해석을 유지합니다. 중복 매핑 키는 계속 오류이며, 지원되는 언어 키의 중복 오류는 DuplicateLanguageCode로 변환합니다. 스트리밍 스키마 검증이 알 수 없는 필드를 먼저 거부하므로 이를 언어 키로 잘못 분류하지 않습니다.

Serde의 untagged 및 internally tagged 버퍼링은 숫자를 타입이 정해지지 않은 표현으로 읽습니다. serde-saphyr는 허용된 비유한 숫자를 정규화된 문자열로 표현하므로 로더에서 이 표현을 활성화하고 .nan, .inf, -.inf만 복원합니다. 기존 surgery 검증은 비유한 배율, 계수, 비율을 계속 거부합니다. 일반적인 따옴표 숫자는 계속 유효하지 않습니다. 명시적인 호환성 변경은 따옴표로 감싼 정규화된 특수 값도 따옴표 없는 값과 같은 처리를 받는 점과 파서 진단 출력 형식입니다.

## 변경 요약

잠금 파일에서 지원되지 않는 두 패키지를 제거하고 대체 파서의 의존성만 추가했습니다. 회귀 테스트는 중복 스키마 필드, 숫자 항목 순서, 불리언 표기, 비유한 숫자의 작업 검증 및 배포된 surgery YAML 예제 6개를 다룹니다. 공개 함수 시그니처와 모델 실행 경로는 그대로입니다.

## 검증

언어 바이어스 집중 테스트 34개와 surgery 설정 테스트 28개를 통과했습니다. 추가한 factor/alpha/ratio 비유한 숫자 및 따옴표 특수 값 회귀 테스트도 통과했습니다. cargo deny check의 advisories, bans, licenses, sources 검사와 포맷 및 패치 검사를 통과했습니다. Python 도구 테스트 123개와 WebUI 픽스처 49개를 포함한 저장소 계약 검사도 통과했습니다. 최종 테스트와 CI Clippy, CPU 전용 링크, cargo-deny는 dd36abb9b321fa6eb6c9abaca07f5690ead72a17에서 확인했습니다. 중복된 로컬 CUDA Clippy 재빌드는 CI Clippy 성공 후 중단했습니다.
