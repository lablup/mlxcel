# 기술 보고서: PR #1977, Models 화면 분할, overflow 훅과 포맷 캐시

**날짜**: 2026-09-26

**상태**: 구현, 리뷰, 로컬 검증 완료. 이 보고서를 만든 chain 실행이 머지함.

**언어**: TypeScript/React

**위험도**: 낮음

## 요약

PR #1977은 이슈 #1976을 닫는다. #1976은 PR #1975 보고서의 "남은 항목" 4개를 묶은 이슈다. 이 PR은 다음을 한다.

- Models 화면을 기존 경계를 따라 동작 변경 없이 나눈다.
- 공용 overflow 영역 훅이 늦게 마운트되거나 교체된 테이블을 따라가게 하고, 포커스된 탭 정지점은 blur 전까지 유지하게 한다.
- 공용 Intl 포매터 캐시에 크기 제한을 둔다.

또 #1975 보고서를 정정했다. 그 보고서는 저장소에 없는 500줄 모듈 규칙을 인용했다. 실제 기준인 `docs/code-guidelines.md`는 800줄 미만 파일을 문제없다고 본다. 분할의 근거는 크기가 아니라 응집도다.

## 문제 정의

- `ModelsLibrary`는 행 포커스, 컬럼 정의, 툴바, 페이지 구성을 모두 담은 731줄짜리 함수 하나였다.
- `useOverflowRegion`은 ref가 붙을 때 내부 `<table>`을 한 번만 찾았다. 지금 호출하는 쪽 중에 테이블을 나중에 마운트하는 곳은 없지만, 앞으로 그런 호출자가 생기면 그 테이블은 관찰되지 않는다.
- 포커스된 스크롤 박스가 더 이상 넘치지 않으면 훅이 `tabindex`를 지워 포커스가 `<body>`로 떨어졌다.
- export된 `cached()`에는 크기 제한이 없었다. `features/chat/time.ts`에는 크기 제한 없는 비공개 사본이 따로 있었다.

## 변경 요약

- **분할(별도 커밋 `e79df10c`):** 화면이 새 모듈 셋을 쓴다.
  - `row-focus.ts`: `useRowFocus()` 훅과 `AFTER_LOAD`, `AFTER_UNLOAD` 상수.
  - `columns.tsx`: `libraryColumns(context)`.
  - `toolbar.tsx`: `LibraryToolbar`.

  `screen.tsx`는 731줄에서 433줄이 됐다. 옮긴 코드는 감싸는 줄을 빼면 기존 코드와 같고, effect 순서도 그대로다. 기존 테스트는 수정 없이 통과한다.
- **Overflow 훅:**
  - `MutationObserver`가 영역 하위 트리의 `childList`를 관찰해, 관찰 대상 테이블을 다시 찾는다.
  - 그 변화로 인한 overflow 검사는 `requestAnimationFrame` 하나로 묶는다. 그래서 폴링이나 SSE 몰림으로 인한 행 변경은 프레임당 레이아웃 읽기가 최대 한 번이다.
  - `characterData`는 관찰하지 않으므로 텍스트만 바뀌면 깨어나지 않는다.
  - 박스에 포커스가 있는 동안은 탭 정지점을 유지하고, 한 번만 도는 `blur` 리스너가 검사를 다시 실행한다.
- **캐시:** `cached()`는 `CACHE_LIMIT = 32`개까지만 보관하고, 가장 먼저 들어온 항목부터 버린다. `chat/time.ts`는 이제 공용 헬퍼를 쓴다.

## 기술적 선택과 그 이유

- **변화로 인한 검사를 프레임 단위로 묶었다.** 첫 버전은 observer 콜백에서 검사를 동기로 돌려, SSE가 몰리면 React 커밋마다 레이아웃 읽기를 강제했다. 구현 리뷰가 이를 MEDIUM으로 지적했고 push 전에 고쳤다. 부착 시점 검사와 ResizeObserver 경로는 동기로 남겼다.
- **포커스를 다른 곳으로 옮기지 않고 blur 전까지 탭 정지점을 유지한다.** Models 영역은 label로 이름이 붙고 heading이 없다. Activity의 `<h3>`는 포커스를 받을 수 없다. 두 화면에 공통으로 포커스를 보낼 대상이 없다.
- **키 타입을 제한하지 않고 FIFO 한도를 둔다.** 호출자가 숫자로 키를 만들기 때문에, 고정 키만 허용하는 타입 제한은 성립하지 않는다.

## 검증

- **로컬 검사:** typecheck와 lint 통과, 유닛 스위트 통과(node 테스트 35개, Vitest 713개), 기본 Chromium Playwright 전체 124개 통과. `build_bundle.py --verify`, binary-asset 검사, contract 검사도 통과했다.
- **수정 없이는 실패하는 테스트:** 새 훅 테스트와 캐시 테스트는 main 소스에서 실패함을 확인했다.
- **리뷰:** 보안 리뷰에서 CRITICAL이나 HIGH는 나오지 않았다.

## 남은 항목

- **미지원 환경:** `ResizeObserver`가 없는 환경에서는 `MutationObserver`도 설정되지 않는다. 현재 브라우저에는 해당하지 않는다.
- **창 blur:** `blur`는 창 전체가 포커스를 잃을 때도 발생하므로, 그때 포커스된 채 줄어든 박스는 탭 정지점을 잃는다.
- **공유 한도:** `CACHE_LIMIT`는 모든 캐시 맵이 함께 쓴다. 현재 호출자들은 이 한도보다 훨씬 적게 쓴다.
