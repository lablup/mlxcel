# 기술 보고서: PR #1894 — 크기가 제한된 로컬 스트리밍 채팅

**날짜:** 2026-09-14 · **상태:** 부분 완료, 통합 및 실환경 검증 대기 · **위험도:** 중간 · **언어:** TypeScript/React, Rust

## 동작과 경계

Chat은 npmjs에 배포된 ui-common 어댑터와 승인된 공통 셸을 사용합니다. 기존 인증된 OpenAI 스트리밍 핸들러를 호출하며 턴마다 UI의 불투명 ID, 실제 추론 ID와 카탈로그 리비전을 고정합니다. 취소·중단·오류의 부분 출력을 보존하고 추론 과정과 실행하지 않는 도구 호출을 구분하며 서버 토큰 사용량과 클라이언트 관측 시간을 별도로 표시합니다. 다른 생성기, 자동 모델 로드, 도구 실행이나 원격 미디어 가져오기를 추가하지 않습니다.

제한된 Markdown 렌더러는 HTML과 원격 이미지를 차단하고 표시 문자·블록 수를 제한하며 완료된 코드 블록만 로컬에서 지연 강조합니다. 이미지 입력은 실제 서버 제한과 별도의 더 낮은 브라우저 메모리·요청 제한을 적용합니다. Bootstrap은 단일 서버의 실제 설정 기반 추론 JSON 상한과 풀 모드의 라우터 전달 버퍼 상한을 구분하여 제공합니다. 관리 API의 2 MiB 상한을 추론 상한으로 잘못 사용하지 않습니다. 최종 UTF-8 JSON 검사에는 대화 기록, base64와 요청 외피를 모두 포함합니다.

기록은 명시적으로 저장을 켜기 전에는 메모리에만 있습니다. 버전이 지정된 IndexedDB 어댑터는 대화·턴·바이트 및 별도 동의한 이미지 저장을 제한하고 알 수 없는 필드·버전을 거부합니다. 복원된 진행 중 턴은 중단으로 표시하며 저장 용량 오류와 전체 삭제를 처리합니다. 가져온 이미지는 미리보기나 재전송 전에 헤더·크기를 재검증합니다. 삭제·가져오기·로드의 늦은 콜백과 스트리밍 갱신은 화면 해제·기록 교체 이후 데이터를 부활시키지 못하도록 차단합니다. 과거의 불변 턴 바이트 크기는 캐시하여 매 프레임 전체 기록을 직렬화하지 않습니다.

## 리뷰 후 수정

독립 리뷰에서 발견한 늦은 기록 작업, 가져온 이미지의 메모리 제한 우회, 첨부 파일 읽기 중 화면 전환, 무효한 transcript 메모화, Clipboard API 부재 처리, 거짓 완료 기록 및 이미지 비활성화가 텍스트 채팅까지 차단하는 문제를 수정했습니다. Provider 취소 테스트에서는 reader 취소가 abort 거부보다 먼저 읽기 완료를 반환하는 별도 경쟁 상태도 발견했습니다. 공통 클라이언트가 경쟁 이후 abort 상태를 다시 검사하여 취소된 전송을 성공 EOF로 보지 않도록 수정했습니다.

선택 변경의 관측 전용 취소 및 제출의 인증 세션 경계는 선행 Settings/Activity PR이 소유합니다. 중복 개발 변경은 명시적으로 이관했으며 이 이슈에 겹쳐 쌓지 않았습니다. 최종 리베이스 후 공통 Settings 기본값과 로컬 요청별 조정을 연결해야 합니다. 현재 체크포인트는 서버 기본값을 사용합니다. 두 독립 리뷰 모두 선택 통합과 실모델 검증을 남은 조건으로 기록했습니다. Safari/VoiceOver 및 실제 200% 확대는 사용자가 최종 에픽 검증으로 연기했으며 개별 승인 요청을 반복하지 않습니다.

## 실행한 검증

- 최초 게시본의 프런트엔드 단위 테스트 136개, TypeScript 및 ESLint가 통과했습니다. 이후 리뷰 수정의 대상 테스트도 통과했으며 최종 합계는 PR 인계에 기록합니다.
- CPU 전용 미디어 제한 투영 테스트 2개와 실제 라우트 전체 bootstrap 픽스처 테스트 1개가 통과했습니다. 서로 다른 가로·세로 제한 및 라우터/단일 모드 본문 상한을 검증했습니다.
- `cargo clippy --lib --tests --features metal,accelerate -- -D warnings`가 통과했습니다. 네이티브 의존성의 기존 미사용 HIP 소스 경고는 Rust lint 실패가 아닙니다.
- 엄격한 계약 픽스처 46개, 생성 DTO 일치, 스키마 음성 테스트, 호환성·버전·커널 키 검사가 통과했습니다. 결정적 번들은 기존 크기 예산을 유지하며 로컬 지연 강조 청크를 포함합니다.
- 이 작업에서는 로컬 브라우저 렌더러, 전체 Rust 테스트 또는 GPU 실모델 추론을 실행하지 않았습니다. 호스티드 브라우저 픽스처와 명시적 격리 서버를 요구하는 실제 브라우저 하네스를 제공하며 설정 누락을 스킵 통과로 처리하지 않습니다.

## 루트가 수행할 남은 검증

#1846/#1847/#1844 이후 리베이스하여 공통 요청 기본값과 관측 전용 모델 선택을 연결하고 최종 lint·단위·계약·번들 검사를 반복합니다. 호스티드 밝은·어두운·좁은 화면 접근성 및 10,000토큰 크기 렌더링을 검증하며 실제 스크린샷을 검토하지 않고 기준 이미지를 갱신하지 않습니다. dense 및 hybrid/MoE 모델과 제공자가 확인한 VLM 이미지에 실제 브라우저 하네스를 실행하고 출력의 타당성을 검토하며 Stop 후 격리 서버의 활성 요청 수가 0으로 돌아오는지 확인해야 합니다. 모두 대기 조건이며 픽스처나 컴파일 성공으로 대체하지 않았습니다.
