# 기술 보고서: PR #2949 — 벤치마크 근거 통합

**작성일**: 2026-11-11
**상태**: 구현 완료, 머지 대기
**위험도**: 낮음

## 요약

`docs/benchmark_results`의 추적 파일을 2,015개(14.4 MB)에서 70개(1.04 MB)로 줄였다. 조사 142건을 버전별 문서 12개로 통합하면서 최종 결과, 최소 근거 데이터, 부정적 판정, 미측정 항목을 보존했다.

## 문제 정의

로그, 중간 출력, 반복 실험 보고서가 최종 결과 탐색을 방해했다. 성공한 최종 수치만 남기면 기본 비활성화 정책과 잘못된 전제를 수정한 근거가 사라진다. 일부 과거 결과 디렉터리에는 현재 벤치마크 실행기가 import하는 실행 도구도 있었다.

## 기술적 선택과 그 이유

- 최종 보고서와 작은 측정·정확성 데이터는 현재 트리에 남기고, 상세 과거 근거는 커밋 `2dc8ed47b30dc204d892328098e8cc34ec02ddc1` 고정 링크로 복구한다. Git 이력은 변경하지 않는다.
- 버전 분류는 보고서가 처음 포함된 안정 릴리스 기준이며 실제 측정 바이너리 버전으로 간주하지 않는다. 원래 출처와 후속 정정을 보존한다.
- hostgate 구현을 변경 없이 `scripts/bench_hostgate.py`로 이동하고 실행기 import를 테스트한다. 메모리 soak 출력은 추적하지 않는 `bench-results/`로 보낸다.
- 최종 JSONL 데이터 4개를 warmup과 구조화된 필드 값까지 보존하여 CSV로 변환한다. 결과 트리 전체에서 원시 출력을 금지하고 기존 예외 목록은 비어 있도록 검사한다.

## 변경 요약

결과 색인에서 최종 보고서, 미검증 항목, 과거 의사결정을 분리했다. 저장소 참조는 보존 데이터, 통합 문서 앵커, 고정 출처를 가리키도록 수정했다. 제거된 바이너리 예외를 삭제하고 회귀 테스트를 추가했다. 추론 동작은 바뀌지 않았으며 기존 미추적 CSV 4개는 변경 범위에서 제외했다.

## 검증과 한계

제출 전 Python 벤치마크 테스트 70개, 원시 로그·CSV 스키마 검사, 바이너리 검사와 회귀 테스트, 셸 구문 검사, 포맷, Clippy가 통과했다. 보존 데이터의 바이트 동일성과 CSV 변환 필드의 왕복 일치, 새 링크와 통합 문서 앵커를 확인했다. 추론 변경이 없어 실제 모델 성능은 다시 측정하지 않았다. 기존 네이티브 컴파일 경고와 무관한 과거 보고서의 깨진 링크는 범위 밖이다. PR CI와 머지 상태는 이 문서에서 단정하지 않고 GitHub 기록으로 확인한다.
