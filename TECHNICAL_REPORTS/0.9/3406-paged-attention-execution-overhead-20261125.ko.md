# PR #3406: paged attention 실행 오버헤드

**작성일**: 2026-11-25
**상태**: 구현 완료, 플랫폼 검증 범위는 아래에 명시

## 요약

#3385 전체 변경은 별도 GPU 보조 커널과 과도한 CUDA 그래프 분할을 줄인다. GB10의 Qwen3 8B, 입력 8192토큰·B=4에서 1.16% 개선됐다. 오너는 Qwen3 0.6B의 1.16~1.36% 저하를 수용했다. 모든 모델의 처리량 개선이나 FLOPs 감소를 주장하지 않는다.

## 문제 정의

Paged KV slab 전체를 입력으로 등록하면 실제 선택한 페이지만 읽더라도 예약 크기가 CUDA 그래프 바이트 예산에 포함된다. GB10에서는 attention 호출마다 그래프가 제출될 수 있다. 별도 Q→f32 변환과 GPU scale fill도 레이어마다 추가 작업을 만든다.

## 변경 요약

CUDA custom-kernel overlay는 paged-attention 입력을 바이트 예산에서 제외하되 의존성 추적과 출력 집계는 유지한다. 공유 v2 커널은 Q를 적재하며 변환하고, host 데이터로 초기화한 scale 배열을 사용한다. fp16 Q와 명시적으로 f32로 변환한 Q의 출력 바이트가 B=1·B=2에서 일치하는 회귀 테스트를 추가했다.

Q 변환 자체는 남으며 파티션마다 반복될 수도 있다. 산술 연산이 제거됐다는 의미가 아니다. 별도 변환 커널, 중간 f32 배열, fill 커널과 과도한 그래프 제출을 줄이는 것이 이점이다. 그래프 묶음 방식은 attention 수학을 바꾸지 않는다.

## 기술적 선택과 그 이유

Budget-only 대신 전체 변경을 채택한다. 8B 전체 변경의 라운드별 개선은 +0.86%, +1.24%, +1.12%였다. Budget-only 전체 중앙값은 +0.12%로 대조군과 겹쳤으며, 라운드별 변화는 -1.23%, +0.06%, +0.19%였다. 기존 무회귀 수용 기준은 작은 모델의 저하를 수용한 오너 결정으로 명시적으로 변경됐다.

이전 프로파일의 커널·그래프 수는 0.6B 실험과 별도의 sliding-window 브랜치에서 측정했으며 8B 측정값이 아니다. 벤치마크 바이너리는 최신 main 통합 이전 버전이다. 현재 통합 결과는 관련 테스트로 검증했으며 성능을 재측정하지 않았다.

## 검증

Main 7a66c862 통합 후 관련 CUDA 테스트 256개 통과, 1개 ignored. 신규 fp16 동등성 테스트가 실제 실행됐다. Core clippy, 포맷, 커널 dtype-key 및 port-dispatch 검사 통과. 측정한 8B 요청 144개 모두 3072토큰을 생성했고 해당 대조군과 출력 해시가 일치했다. 로컬 검증 정책에 따라 원격 CI는 취소하며, 이를 CI 통과로 간주하지 않는다. Metal·HIP 실행은 미검증이다.

원시 결과와 바이너리 해시: [벤치마크 기록](../../docs/benchmark_results/issue-3385-qwen3-8b-gb10-2026-11-24/README.md).
