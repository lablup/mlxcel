# 기술 보고서: PR #2677 — 바이너리 패리티 픽스처 선언

**작성일**: 2026-10-27
**상태**: 완료
**위험도**: 낮음

## 요약

앞선 FLUX.2/Z-Image 수정 #2675와 동시에 추가된 Bonsai 픽스처 때문에 실패한 바이너리 자산 검사를 복구했다. 허용 목록만 수정하며 기존 바이너리 내용이나 테스트 동작은 변경하지 않는다.

## 문제 정의

이미지 생성 패리티 테스트가 사용하는 Bonsai 픽스처 세 개에 정확한 크기 선언이 없었다. PNG는 일반 합성 이미지 한도를 넘었고 텐서는 선언되지 않았다. 이 오류는 main에서도 재현되어 관련 없는 #2574 변경의 검사까지 실패시켰다.

## 변경 요약

세 파일의 정확한 경로와 실측 크기를 선언하고 합계 1,452,561바이트를 기존 총 허용량에 더했다. 앞선 #2675는 FLUX.2/Z-Image 픽스처 8개, 합계 2,834,247바이트를 같은 방식으로 선언했다. 두 변경 모두 일반 이미지 제한을 완화하거나 임의의 새 바이너리 경로를 허용하지 않는다.

`python3 scripts/ci/check_binary_assets.py`가 통과했다. 선언한 바이너리는 103개이고 총 40,272.0 KiB로 40,472 KiB 한도 안에 있다. `git diff --check`도 통과했다. 이후 픽스처 추가에도 명시적 선언과 크기 근거가 필요하다.
