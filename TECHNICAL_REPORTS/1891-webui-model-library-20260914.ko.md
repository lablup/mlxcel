# 모델 라이브러리 WebUI — PR #1891

날짜: 2026-09-14. 상태: 열린 PR, 구현 리뷰 완료, 통합 게이트는 미완료. 이슈: #1844, 상위 에픽: #1834.

## 범위와 구조

Models 경로는 기존 인증·스키마 가드 뒤에서 로컬 카탈로그를 표시합니다. 별도 fetch 클라이언트, Bearer 토큰 저장소, 선택 상태, 지원 규칙 또는 모델 수명주기를 만들지 않고 공통 provider를 사용합니다. npmjs 배포 패키지 `@lablup/ui-common@0.1.0-alpha.19`의 Button, Select, DataTable, StatusTag, ProgressBar, EmptyState를 기존 어댑터로 사용하며, 대화상자는 문서화된 네이티브 최상위 레이어 구성을 유지합니다. 업스트림 컴포넌트 소스는 복사하지 않습니다.

`features/models/policy.ts`는 최신 서버 스냅샷, 작업 가용성, 수명주기와 삭제 자격으로 실행 가능 여부를 계산합니다. `screen.tsx`는 명시적 작업을 조율하고 `dialogs.tsx`, `inspector.tsx`, `operations.tsx`는 확인·메타데이터·관측 결과를 표시합니다. 기능 CSS는 배치만 담당하며 승인된 공통 macOS 디자인을 유지합니다. 영어·한국어 문구는 `models.library.*` 네임스페이스와 공통 문자열 픽스처에 포함됩니다.

## 운영 흐름

로컬 검색, 소스·작업·수명주기 필터와 정렬은 외부 모델 마켓에 연결하지 않습니다. 타입이 지정된 표는 페이지당 최대 25개 행을 렌더링하며 필터와 무관하게 공통 opaque 선택 ID를 유지합니다. 상세 패널은 아키텍처 지원, 실제 백엔드 실행 가능 여부, 체크포인트 검증, 파일 완전성, 디스크 바이트와 예상 메모리를 구분합니다. null은 알 수 없음으로 남깁니다. 실제 컨텍스트는 동일 리비전의 런타임에 숫자 값이 있을 때만 표시하며 계열의 이론적 최대치를 대신 쓰지 않습니다.

로드는 현재 모델 리비전과 새 멱등성 키를 사용합니다. HTTP 202만으로 클라이언트 수명주기를 변경하지 않습니다. 비동기 로드 충돌 실패에는 활성 모델 검토와 명시적인 유휴 교체 대상 선택을 제공하며, 모든 충돌이 용량 때문이라고 단정하거나 자동 재시도하지 않습니다. 언로드 확인은 활성 요청 배출과 작업자 종료를 파일 삭제와 구분합니다. 캐시 삭제는 서버가 허용한 관리 캐시 항목에만 제공하고 정확한 표시 이름을 입력받으며, 대화상자를 열 때의 리비전·서버 인스턴스를 유지합니다. 사용자 제공 경로에는 디스크 삭제를 제공하지 않습니다.

모델 추가는 공개·비게이트 확인, 서버와 일치하는 저장소·리비전 구문, 네트워크·목적지 고지를 요구합니다. 거부된 요청은 입력과 서버 오류를 유지합니다. 관측된 작업은 바이트 진행률 또는 불확정 표시, 취소, 실패·취소 다운로드의 새로운 명시적 재시도를 제공합니다. 단일 모델 모드는 수명주기·라이브러리 변경과 재검색을 비활성화하고 관측 새로고침과 재시작 안내를 유지합니다.

## 리뷰 수정과 공통 의존성

독립적인 읽기 전용 리뷰 두 건에서 발견한 기능 내부 문제를 수정했습니다. 일반적인 용량 실패는 HTTP 409가 아닌 202 이후 작업 실패로 전달되므로 해당 복구 경로를 추가했고, 단일 모델 재검색을 막았으며, 저장소·리비전 경계를 서버와 맞추고 거부된 다운로드 입력을 보존했습니다. 브라우저 픽스처도 정식 opaque ID, 응답 전체 JSON 검증, 삭제된 런타임의 실제 404를 사용하도록 고쳐 성공을 꾸며 내지 않도록 했습니다.

다음 공통 문제는 중복 구현하지 않고 에픽 조율자가 지정한 선행 이슈에서 해결합니다.

- #1846: 전달된 네이티브 대화상자 언마운트 포커스 복원 및 회귀 테스트 8개, 변경 요청의 인증 세션 경계, 공통 로드 프로필 어댑터.
- #1847: 전체 카탈로그에서 사라진 선택 모델을 조정하여 런타임 404·오프라인 반복을 방지하는 처리.
- #1845: 상세 확인이나 선택이 진행 중인 추론·변경 요청을 취소하지 않도록 취소 범위를 분리하는 처리.

현재 로드 요청은 의도적으로 서버 기본값을 사용합니다. #1846 머지 후 정식 `useLoadProfile` 훅을 연결해야 최종 승인할 수 있습니다. 상세 패널은 이 경계를 명시하며 중복 설정 저장소는 커밋하지 않습니다.

## 남은 승인

다운로드·로드·선택·언로드·삭제 모의 여정과 데스크톱 라이트·좁은 다크/불투명 화면의 대규모 CJK 목록 키보드·접근성을 다루는 브라우저 테스트 3개를 작성했습니다. 중앙 조율자가 이 Mac의 GPU를 예약하고 있어 로컬 실행은 하지 않았습니다. 호스팅된 CI 실행과 변경된 로그인 후 Models 스크린샷 리뷰가 남아 있으며 승인 없이 기준 이미지를 변경하지 않았습니다. 모의 HTTP 응답은 실제 체크포인트 다운로드·추론·배출·파일 삭제의 증거가 아닙니다.

공통 선행 수정과 프로필 연결 후 root 통합 게이트에서 새 임시 경로에 다운로드한 작은 실제 체크포인트로 전체 브라우저 여정을 검증해야 합니다. 기존 사용자 체크포인트는 건드리지 않습니다. Safari/VoiceOver와 실제 페이지 확대 200%는 사용자 결정에 따라 최종 통합 수동 세션으로 연기했으며 통과로 기록하지 않습니다. 이 프런트엔드 단위 작업은 CUDA/GB10 또는 광범위 Metal 검증 결과를 주장하지 않습니다.

## 실행된 호스팅 브라우저 증거와 리플로 수정

실행 `34849720039`, 작업 `103994435003`에서 브라우저 테스트 23개 중 20개가 통과하고 3개가 실패했습니다. 새 대규모 CJK 목록 키보드·axe·레이아웃 테스트 두 건은 통과했습니다. 작업 여정은 삭제까지 진행한 뒤 알려진 선택 모델 런타임 404로 결과 조정이 남아 올바르게 실패했습니다. 해당 단언을 완화하지 않고 #1847에서 선행 문제를 해결해야 합니다. 로그인 후 스크린샷 두 건도 달랐습니다. Root 시각 리뷰는 데스크톱 방향은 수용했지만 좁은 화면의 잘림을 거부했으며 기준 이미지는 승인·교체하지 않았습니다.

좁은 화면 문제는 opaque 작업 제목이 암시적 그리드 트랙을 늘린 데서 발생했습니다. 수정 레이아웃은 최소 폭이 0인 명시적 트랙을 사용하고 작업 ID와 버튼 그룹을 줄바꿈하며 상세 패널이 없으면 표가 가용 폭을 사용합니다. overflow를 숨기지 않습니다. 작업 제목은 카탈로그 표시 이름을 우선하며 opaque ID를 따로 유지합니다. 기존 로그인 후 스크린샷 테스트는 로그인 전뿐 아니라 로그인 후에도 안전한 배치와 axe를 검사하며, 포함된 작업 정보로 누락된 조건을 검증합니다. 수정 후 로컬 단위 테스트 113개와 타입 검사·린트가 통과했지만 변경된 호스팅 렌더링은 재검토가 필요합니다.
