# 모델 라이브러리 WebUI — PR #1891

갱신: 2026-09-15. 이슈 #1844, 에픽 #1834. 검증 구현: `22f19d9eb7836c4b33333724294980a3ecfb9168`. 로컬 브라우저와 격리된 실제 모델 수명주기 검증은 통과했습니다. 이 보고서 시점의 통합 및 수동 게이트는 아직 남아 있습니다.

## 구현과 사용자 제어

인증된 Models 화면은 공통 provider와 npmjs `@lablup/ui-common@0.1.0-alpha.19` 어댑터를 사용합니다. 컴포넌트 소스를 복사하거나 별도 모델·토큰 저장소를 만들지 않았습니다. 로컬 검색·필터·정렬과 25행 페이지 이동은 opaque 선택을 유지하며 외부 마켓 검색이나 암시적 로드를 하지 않습니다. 상세 정보는 아키텍처 지원, 체크포인트 검증 근거, 완전성, 디스크 용량, 알 수 없는 메모리 추정치, 리비전이 일치하는 실제 컨텍스트를 구분합니다.

공개 다운로드는 명시적 동의와 저장 위치·네트워크 사용 안내를 요구합니다. 작업의 진행·취소·실패·재시도는 HTTP 202를 완료로 간주하지 않습니다. 언로드는 워커 종료를 관측합니다. 디스크 삭제는 별개이며 서버가 허용한 관리 캐시만 대상으로, 체크포인트 이름과 opaque ID를 표시하고 정확한 ID 입력을 요구합니다. 사용자 제공 루트에는 삭제 기능을 제공하지 않습니다.

Settings의 정식 프로필은 선택이 바뀐 용량 충돌 복구를 포함해 실제 명시적 로드 대상에 적용합니다. 모델 프로필은 재사용 기본값을 대체하며 요청 값을 복사합니다. 저장은 모델 로드나 서버 설정 변경이 아닙니다. 명시적 CLI·환경 설정이 우선합니다. 용량 확인 시 교체 대상 ID와 리비전을 고정하고, 서버는 작업 승인 및 대기 후 실행에서도 검증하며 작업 식별·멱등성에 포함합니다. 교체 대상의 오래된 리비전 오류는 `eviction_target_expected_revision`, 로드 대상 오류는 `expected_revision`으로 구분합니다.

## 실제 검증으로 발견한 결함

실제 다운로드한 SmolLM이 Ready에 도달했는데도 Use in Chat이 비활성 상태였습니다. UI 제한은 올바랐으며, 카탈로그가 Chat/Completion의 pre-load 정보만 제공한 것이 원인이었습니다. 백엔드는 이제 로드된 provider 근거, Ready 수명주기, 지원되는 선언 출력 작업을 모두 만족할 때 별도 provider-ready 텍스트 정보를 추가합니다. 매번 동적 정보를 제거한 뒤 재구성하여 pre-load 메타데이터를 보존하고 중복 및 언로드·실패 후 잘못된 가용성을 방지합니다. 수정 전 회귀 테스트 2개가 실패했고 수정 후 카탈로그 CPU 테스트 30개가 모두 통과했습니다.

통합 브라우저 검증에서는 Activity의 필수 `slots`가 빠진 runtime 픽스처도 발견했습니다. 실제 응답 생성 함수를 정식 snapshot에서 구성하고 수명주기·엄격한 스키마 회귀 테스트를 추가했습니다. 스키마나 pending=0 단언은 완화하지 않았습니다. Root는 Linux/Darwin 각각 로그인 후 Models 기준 이미지 2개만 검토·승인했으며 갤러리·로그인 기준과 비교 허용치는 유지했습니다. 자동 시각 검토이며 네이티브 Safari 통과는 아닙니다.

## 남은 게이트

최종 로컬 WebUI 켬·끔 workspace 전체 타깃 Clippy와 소스 CI는 위 결과대로 통과했으며 생략 작업을 실행 검증에 포함하지 않습니다. 새 전체 workspace Metal 테스트 통과는 주장하지 않으며 최종 #1848 통합 게이트로 남깁니다. 통합 Chat 생성과 화면 간 검증은 #1845/#1848 범위입니다. Safari/VoiceOver와 네이티브 실제 200% 확대는 종합 수동 검증으로 연기했습니다. GPU 타임아웃의 근본 원인 조사는 사용자 결정으로 연기되었으며 이번 제한된 수명주기 성공이 GPU 안정성을 증명하거나 해당 조사를 해결하지는 않습니다.
