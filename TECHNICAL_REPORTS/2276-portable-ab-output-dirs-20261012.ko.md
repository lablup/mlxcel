# 기술 보고서: PR #2276 - 이식 가능한 A/B 출력 디렉터리

**작성일**: 2026-10-12
**상태**: 리뷰 준비 완료
**언어**: Bash
**위험도**: 낮음

## 요약

A/B 출력 동일성 게이트와 paged decode 게이트가 이제 GNU와 BSD `mktemp` 모두에서 허용되는 템플릿으로 기본 산출물 디렉터리를 만듭니다. 기본 또는 요청한 출력 디렉터리를 만들 수 없으면 각 게이트는 모델을 실행하거나 산출물을 쓰기 전에 명확한 오류를 출력하고 종료 상태 2를 반환합니다.

## 1. 문제 정의

GNU의 `mktemp -d -t <prefix>`는 `X` 자리표시자가 없는 접두사를 거부합니다. 이전 스크립트는 이 실패 뒤에도 빈 `OUT_DIR`로 계속 실행되어, 설정 실패를 모델 오류로 잘못 보고하거나 파일 시스템 루트에 출력 경로를 만들 수 있었습니다.

## 3. 기술적 선택과 그 이유

### 경로 템플릿 사용 및 실행 전 실패 처리

두 스크립트는 GNU/Linux와 macOS에서 모두 동작하는 `${TMPDIR:-/tmp}/<gate>.XXXXXX`를 사용합니다. 이후 가드는 빈 디렉터리 값 또는 실패한 `mkdir -p`를 스크립트의 판정 불가 종료 상태로 처리하므로, 이후의 모든 산출물 경로는 검증된 디렉터리 아래에 남습니다.

회귀 테스트 픽스처는 실제 체크포인트나 서버 없이 전체 셸 흐름을 실행하기 위해 stub 바이너리와 HTTP 도구를 사용합니다. 가짜 curl은 파이프된 요청 본문을 소비하여 가짜 jq 생산자에서 발생하는 간헐적인 SIGPIPE 없이 실제 파이프라인의 `pipefail` 동작을 보존합니다.
