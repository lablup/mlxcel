# 기술 보고서: PR #2681 - 웨이브 0 계약 수정

**작성일**: 2026-10-27  
**상태**: 완료  
**언어**: Rust  
**위험도**: 낮음

## 요약

PR #2681은 에픽 #2574의 웨이브 0 변경이 병렬로 머지된 뒤 전체 워크스페이스 검사에서 드러난 두 계약 오류를 수정합니다. 새 분산 인증 설정을 비밀 유래 데이터 노출 없이 분류하고, 모델 소유 상태의 원자성 검사가 별도 모델 인스턴스 사이의 정상적인 부동소수점 차이만 허용하도록 조정했습니다.

## 1. 문제 정의

`cluster_auth` 추가로 `ServerConfig` 필드는 113개에서 114개가 됐지만 runtime settings 목록과 schema에는 이 필드가 분류되지 않았습니다. DeepSeek-V4 원자성 테스트는 별도 모델 인스턴스의 다음 출력을 절대 오차 0으로 비교했으며, 병렬 실행에서 거절된 호출이 상태를 진행시키지 않았는데도 약 `1.5e-7`의 차이가 나타났습니다.

## 2. 기술적 선택과 그 이유

`cluster_auth`는 읽기 전용 분산 설정으로 분류합니다. Schema 값은 `{ "configured": true|false }`만 제공하므로 인증 핸들과 비밀에서 파생된 데이터는 settings 응답에 포함되지 않습니다. 회귀 검사는 실제 인증 핸들을 생성해 이 표현을 검증합니다.

엄격한 B=1 경로 검사는 오차 0을 그대로 유지합니다. 별도 모델 인스턴스를 사용하는 거절 후 상태 불변성 비교에만 `1e-5`를 적용하며, 이는 기존 6단계 모델 소유 parity 검사의 기준과 같습니다. 잘못된 행 수와 누락·중복 ID는 계속 상태 변경 전에 실패해야 합니다.

## 3. 변경 요약

| 영역 | 변경 |
|---|---|
| Runtime settings | 소스 순서의 114개 필드를 모두 분류하고 인증 설정 여부만 노출 |
| 배치 디코드 테스트 | 별도 모델 원자성 비교에 기존 f32 허용치 적용 |
| 보안 | 비밀 유래 인증 상태의 직렬화 방지 |
