# 모델 소유 어텐션 계열의 네이티브 배치 디코드

**PR**: #2673 · **이슈**: #2570 · **에픽**: #2574 · **날짜**: 2026-10-27

## 결과

AFMoE, DeepSeek-V4, IQuestLoopCoder, Inkling은 시퀀스별 상태를 격리한 네이티브 배치 디코드를 제공합니다. Inkling VLM은 텍스트 디코드를 위임합니다. 단일 행은 기존 스칼라 경로를 유지하며 마스크나 여러 토큰 입력은 시퀀스 ID를 보존한 행별 경로를 사용합니다. 합성 다단계 테스트는 길이가 다른 이력, 새 요청, 캐시 증가와 DeepSeek 풀링 경계를 검증합니다.

## 구현과 리뷰

임베딩·정규화·프로젝션은 배치로 실행하고 어텐션은 각 행의 상태를 사용합니다. DeepSeek의 풀링 위치, IQuest의 두 패스, Inkling의 합성곱 상태를 보존합니다. 잘못된 차원·행 수·캐시 수와 누락·중복 ID는 상태 변경 전에 거절합니다. 페이지드 메모리 집계는 실제 캐시 길이를 반영하며 여러 행의 연결은 한 번에 수행합니다.

초기 AFMoE 구현은 단일 요청의 전체 융합 전문가 커널을 배치 전문가 그래프로 바꾸면서 Trinity perplexity가 15.440% 증가했습니다. 최종 구현은 해당 커널이 지원되는 경우 전체 융합 전문가 경로를 행별로 유지하고 나머지 연산을 배치로 처리합니다. 지원하지 않거나 비활성화된 경우 기존 배치 경로를 유지합니다. 독립 리뷰와 집중 회귀 테스트를 통과했습니다.

기존 로그 도구의 기본 배치 호출은 시퀀스 ID를 버려 잘못된 상태를 기준으로 측정했습니다. `MLXCEL_LOGIT_TRACE_SCALAR_REFERENCE=1`과 배치 행 수 1을 함께 사용하는 계측 경로를 추가했습니다. 기준 바이너리는 기존 모델 코드에 이 계측 패치만 적용했으며 초기의 잘못된 로그는 결과에서 제외했습니다.

## 측정

Apple M3 Ultra, 메모리 512 GB, macOS 26.6.2, 릴리스 `metal,accelerate` 환경입니다. 기준 커밋은 `a29a2692`, 최종 Trinity는 `4b6dbbff`, Inkling·DeepSeek은 이후 모델 코드가 바뀌지 않은 `4d076353`입니다. 입력 512 토큰, 최대 출력 128 토큰, 동시성 1/2/4로 측정했습니다. 로그는 256개 위치, 확신도 기준은 상위 두 로짓 차이 2 이상입니다.

| 체크포인트 | 기준 총 tok/s C1/C2/C4 | 최종 총 tok/s C1/C2/C4 | B4 최상위 토큰 차이 | 확신도 기준 차이 |
|---|---|---|---:|---:|
| Trinity Nano Preview 4-bit | 88.1 / 98.4 / 98.9 | 96.6 / 158.4 / 202.3 | 91/256 | 0/16 |
| Inkling 0.6B | 152.9 / 164.8 / 177.4 | 158.1 / 200.6 / 340.9 | 0/256 | 0/96 |
| DeepSeek-V4 Flash 4-bit | 6.8 / 7.3 / 6.4 | 7.9 / 11.5 / 15.4 | 5/256 | 0/129 |

세 모델 모두 기준·최종의 greedy 출력과 수정된 B1 로그가 일치하며 B1 로짓 차이는 0입니다. 최종 Trinity의 B4 perplexity는 69357.6777로 B1의 69864.6970보다 0.726% 낮습니다. 확신도 기준 차이는 없지만 최상위 토큰 차이 91건은 그대로 공개합니다. DeepSeek은 10.9590→10.8562이며 Inkling은 동일합니다. 서버는 제한 없이 네이티브 배치 경로를 기록했습니다.

Trinity의 퇴화된 생성 결과와 높은 perplexity, Inkling의 매우 높은 corpus perplexity는 기준에서도 존재합니다. 이번 결과는 동작 보존과 처리량 검증이며 일반적인 모델 품질을 보장하지 않습니다. IQuestLoopCoder와 Inkling 이미지 경로는 합성·위임 테스트만 검증했습니다. 비루프 IQuest 체크포인트는 루프 모델 검증을 대체하지 않습니다.

## 검증과 기록

집중 네이티브·격리·다단계·위임 테스트, 잘못된 입력의 원자적 거절, 페이지드 집계, 포맷과 대상 clippy 검사를 통과했습니다. 최종 소스 커버리지 계약 12개도 머지 전에 통과했습니다. 전체 워크스페이스 검사는 에픽 최종 통합 단계에서 수행하며 여기서 완료됐다고 주장하지 않습니다.

전체 수치와 비교 로그, 커밋 및 한계는 [`benchmarks/epic-2574/model-owned-attention.json`](../benchmarks/epic-2574/model-owned-attention.json)에 있습니다. `scripts/bench_serving_concurrency.py`의 동시성 1/2/4와 `MLXCEL_TRACE_BATCH_ROWS=1`/`=4`로 재현하며, 기준 로그에는 스칼라 참조 플래그를 추가합니다.
